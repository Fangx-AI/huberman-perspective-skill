# Security and safety policy

## Supported version

Security and medical-safety fixes are accepted for the latest tagged release and the default branch.

## Reporting

Report privately when possible if you find:

- secret, credential or private-data exposure;
- unsafe filesystem or network behavior in a script;
- unsafe over-triggering into diagnosis, treatment changes or unrelated questions;
- medical output that encourages diagnosis, medication changes, dangerous dosing, extreme exposure or delayed urgent care;
- copyrighted or paywalled payloads accidentally included in a release.

Do not include patient-identifying information, access tokens or proprietary source text in a report. Use a [private security advisory](https://github.com/Fangx-AI/huberman-perspective-skill/security/advisories/new) for sensitive reports. If that channel is unavailable, open only a minimal issue describing the category without publishing the sensitive payload.

This project is informational software, not a medical device. For a medical emergency, contact local emergency services rather than the repository maintainers.
