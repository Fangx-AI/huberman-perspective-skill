# Huberman 框架提炼方法

> 从公开内容与研究记录中提炼可运行的健康指导框架。方法结构参考 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 的三重验证，并针对健康建议增加证据、安全和用户结果门。

## 目标

提炼的是 Huberman 公开内容中反复使用的思考方式，不是协议清单、名言集合或第一人称角色模仿。

候选框架只有在能改善以下至少一项时才值得进入产品层：

- 帮用户选择更合适的下一步；
- 减少不必要的复杂度、成本或健康焦虑；
- 更诚实地表达证据强度和不确定性；
- 识别应停止自我实验并寻求专业照护的情况。

## 从材料到用户帮助

```text
官方节目、长视频、课程、论文与外部批评
                  ↓
references/research/ 六维研究底稿
                  ↓
候选思维模式与决策启发式
                  ↓
五道提炼门
                  ↓
huberman-operating-model.md
                  ↓
action-playbooks.jsonl + coaching-guide.md
                  ↓
自然语言用户请求
                  ↓
独立前向测试与保真度评分
```

研究目录是断点和来源层；操作模型是提炼层；行动剧本是可执行层；用户回答是产品层。不能用后一层反向伪造前一层证据。

## 五道提炼门

### 1. 跨情境复现

同一思考方式应至少出现在两个不同主题或内容情境中，例如睡眠与专注、学习与运动恢复。只在一期节目或一项商业产品中出现的建议，不升级为核心模型。

通过标准：

- 有两个以上独立内容情境；
- 能指出相应官方来源或研究底稿位置；
- 不是同一期内容被多个平台重复搬运。

### 2. 有生成力

模型应能帮助处理没有现成协议的新问题。它必须改变选择顺序、询问重点、行动设计或停止条件，而不只是换一种方式复述已知结论。

检查问题：

- 面对新场景，它能否指出先看什么？
- 它是否会排除某些看似合理但不值得做的选项？
- 它能否产生可被现实结果检验的下一步？

### 3. 有辨识度

模型不能只是“睡好、运动、健康饮食”之类所有健康顾问都会同意的常识。它应体现 Huberman 公开内容中有辨识度的组织方式，例如把状态、时间、生理机制、可控杠杆和反馈连接起来。

若一个候选只有普遍正确性，没有独特生成方式，则降级为基础原则，不包装成 Huberman 特有观点。

### 4. 证据可校准

每个模型都必须允许区分：

- Huberman 的直接公开表达；
- 从多期内容归纳出的模式；
- 基于该模式对新问题的推断；
- 独立人体研究、综述或临床指南；
- 尚未验证或存在冲突的部分。

机制合理、动物研究、代理指标、短期状态变化或单项小研究，都不能自动越级为个人长期获益。

### 5. 服务用户且安全

模型必须能被翻译成少量、可逆、可观察的帮助，并保留必要的医学分流。若它只能增加知识量、消费冲动或执行负担，就不进入默认回答。

通过标准：

- 能生成一个现实结果指标；
- 能生成最小版本或退出路径；
- 能说明失败后调整什么；
- 高风险场景能停止生活实验；
- 不需要用户先掌握神经科学。

## 分级规则

| 通过情况 | 归类 | 用法 |
|---|---|---|
| 五道门全部通过 | 核心操作模型 | 可用于新问题路由和框架推断 |
| 跨情境、生成力或辨识度不足，但行动与证据边界清楚 | 决策启发式 | 只在匹配场景使用 |
| 只有特定研究或节目支持 | 情境性主张 | 留在证据卡或主张索引 |
| 无法追溯、风险不可控或只增加复杂度 | 排除 | 不进入用户指导层 |

## 矛盾与张力

矛盾不自动消除，至少分四类记录：

1. **时间性变化**：早期与近期表达不同，保留日期和演化。
2. **领域差异**：同一工具在急性状态与长期适应中的作用不同。
3. **证据张力**：节目表达强度高于直接人体证据或系统综述。
4. **生活适配张力**：理想协议与轮班、育儿、疾病、预算或依从性冲突。

处理时并列呈现条件，不为得到一个整齐结论而强行调和。

## 更新检查点

每次增加一批重要材料后：

1. 运行 `python scripts/research_checkpoint.py`，确认六维底稿和课程层仍可追踪。
2. 只从新材料提出候选，不直接修改核心模型。
3. 按五道门逐项记录通过与失败理由。
4. 新信息若只强化现有模型，补来源和边界；若产生真实冲突，更新张力；只有出现新的生成方式才增加模型。
5. 修改用户行为后，运行独立前向测试和保真度评分。

## 反模式

- 把某个热门协议升级为整套世界观；
- 用 Huberman 的学术身份替节目全部主题背书；
- 把节目嘉宾观点归到 Huberman 本人；
- 把多平台搬运当作跨来源复现；
- 只找支持材料，不保留阴性结果和外部批评；
- 用固定时长、剂量或次数制造虚假精确；
- 为追求“像本人”而冒充本人或伪造引语；
- 用研究数量代替用户帮助质量。

## 提炼记录格式

每个进入操作模型的候选应记录：

- 名称与一句话定义；
- 归类：直接表达 / 跨内容归纳 / 框架推断；
- 至少两个不同情境的来源；
- 它会怎样改变用户帮助；
- 证据和适用范围；
- 失效条件与核心张力；
- 最近核查日期。
